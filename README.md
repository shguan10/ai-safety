# AI Safety

Notes for defending LLMs and LLM agents against jailbreaks and prompt injection.

- [taxonomy.md](taxonomy.md): red-teaming techniques grouped by mechanism, with the measured
  effect of each defence against them, how to evaluate a defence, and a priority list for
  defenders. Reproduces no prompts, templates or suffixes.
- [sources.md](sources.md): the reading list it was built from.
